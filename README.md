# Escalation Matrix Manager

## Overview

Escalation Matrix Manager is a Python command-line application that helps organizations manage support ticket escalations. It tracks escalation levels, ticket ownership, ticket status, and provides statistics and summary reports for efficient incident management.

---

## Features

- Add Support Tickets
- Escalate Ticket Levels
- Resolve Tickets
- Search Tickets
- Pending & Resolved Ticket Tracking
- Escalation Level Statistics
- Summary Dashboard
- Interactive Menu
